# Food Delivery Data Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on cleaning, analyzing, and visualizing food delivery operational data. The dataset was cleaned using Python, followed by exploratory and business analysis. The final insights were presented through an interactive Tableau dashboard.

## Tools & Technologies

* *Python*
* *Pandas*
* *NumPy*
* *Google Colab*
* *Microsoft Excel*
* *Tableau*

## Project Workflow

1. Loaded the raw Excel dataset into Python.
2. Checked dataset structure, data types, missing values, and duplicates.
3. Cleaned missing values and inconsistent text values.
4. Removed duplicate records and standardized columns.
5. Performed exploratory data analysis using Python.
6. Calculated business KPIs such as Total Orders, Total Sales, Average Order Value, and Average Delivery Time.
7. Performed city-wise, cuisine-wise, payment-wise, status-wise, and monthly analysis.
8. Created an interactive Tableau dashboard for business visualization.

## Key Analysis

* Total Orders
* Total Sales
* Average Order Value
* Average Delivery Time
* City-wise Sales
* Cuisine-wise Sales
* Payment Method Analysis
* Order Status Analysis
* Monthly Sales Trend
* Delivery Performance
* Statistical and Outlier Analysis

## Dashboard

The Tableau dashboard provides a simple business view of food delivery performance using KPI cards, bar charts, a line chart, and payment/order-status analysis.

## Project Outcome

The project demonstrates an end-to-end data analytics workflow from *data cleaning and Python analysis to Tableau visualization*, helping identify important sales, order, delivery, and operational trends.
